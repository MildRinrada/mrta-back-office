จัดการถาม-ตอบ (Q&A)

หน้าหลัก จัดการถาม-ตอบ (Q&A) คิวกลั่นกรองคำถามและคำตอบ
รออนุมัติ 0 รายการ รอแก้ไข 0 รายการ อนุมัติ 18 รายการ ปฏิเสธ 0 รายการ จัดเก็บแล้ว 3 รายการ
คู่มือการกลั่นกรองถาม-ตอบ
  1. คำถามและคำตอบจากผู้ใช้เข้าคิว "รออนุมัติ" ก่อนเสมอ หน้าเว็บยังไม่แสดงจนกว่าจะอนุมัติ (คำตอบของเจ้าหน้าที่และคำถามที่เจ้าหน้าที่ตั้งเผยแพร่ทันที)
  2. อนุมัติ = เผยแพร่บนหน้าเว็บ และแจ้งเจ้าของทางกระดิ่งแจ้งเตือน
  3. ให้แก้ไข (เฉพาะคำถาม) = ส่งกลับพร้อมเหตุผล เจ้าของเห็นเหตุผลในหน้าคำถามของตัวเอง แก้แล้วส่งใหม่จะกลับเข้าคิวรออนุมัติ
  4. ปฏิเสธ = ไม่เผยแพร่ ต้องระบุเหตุผลเสมอ เจ้าของได้รับแจ้งพร้อมเหตุผล
  5. จัดเก็บ = เอาคำถามออกจากหน้าเว็บแต่ยังเก็บไว้ ดูหรือคืนสถานะได้ที่แท็บ "ปิดคำถาม / จัดเก็บ"
  6. ปิดรับคำตอบ = คำถามยังแสดงบนหน้าเว็บ แต่ผู้ใช้ตอบเพิ่มไม่ได้
  7. ติ๊กเลือกหลายรายการในตารางเพื่ออนุมัติ / ปฏิเสธ / จัดเก็บพร้อมกัน รายการที่สถานะไม่ตรงจะถูกข้าม
  8. ทุกการดำเนินการบันทึกไว้ใน "ประวัติการดำเนินการ" ของรายการนั้น
คิวกลั่นกรองคำถามและคำตอบ จัดการหมวดหมู่คำถาม ปิดคำถาม / จัดเก็บ
